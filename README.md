# Portfolio

Personal site of Ryan Joshua George, Full Stack Developer. Plain HTML/CSS/JS, served by GitHub Pages.

- `index.html`: about, tech stack, projects, blog index, contact
- `blog/`: posts on AI
- `assets/`: styles and scripts

To add a post, copy a file in `blog/`, edit it, and add a card to the `#blog` section of `index.html`.

The CV at `assets/Ryan_George_Resume.pdf` is built from `resume/Ryan_George_Resume.tex` (e.g. `tectonic resume/Ryan_George_Resume.tex --outdir assets`).
